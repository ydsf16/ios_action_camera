# RoamShot 拍摄截图计划

用户确认夜间不便实拍，改用内置 imagegen 生成白天海岸风景。前两张通过 build 27 的生产 SwiftUI 控件与 Debug 模拟器图像输入生成，标注演示素材；没有使用家庭实拍截图。该图像输入仅在 Debug 模拟器编译，设备与 Release 均不包含。

| 顺序 | 主标题 | 副文案 | 画面要求 |
| --- | --- | --- | --- |
| 1 | 把 iPhone 变成运动相机。 | 旅行、徒步、日常走拍，拿起手机就出发。 | 生产相机控件与生成的海岸取景内容，保留录制键和倍率控件；优先室外、光线充足、无私人信息的场景。 |
| 2 | 拉近远处，拍后稳住。 | 长焦与放大拍摄，也能进行拍后防抖。 | 同一生成场景拉近后的相机控件界面，显示当前倍率；按实际设备支持操作，不将数字变焦称作独立长焦镜头。静态截图只说明功能，不能证明防抖效果。 |
| 3 | 拍完以后，再选稳定感。 | 原片保留，随时调整与导出。 | 已有播放页截图；明确标注风景为 AI 演示素材。后续可用得到授权的真实素材替换。 |
| 4 | 三档稳定，一点就好。 | 自然 / 标准 / 强力 · 支持重力水平锁定 | 已有简洁设置截图，默认 2.8K 输出。 |
| 5 | 先免费拍，再决定。 | 每段 1 分钟免费 · 长时间录制一次买断 | build 27 设置购买页截图，¥20 永久解锁、无订阅；无免费录制按钮。 |

高级控制图放在第六张作为补充，前面的图片集中介绍拍摄和使用价值。不要使用“完全替代专业运动相机”“长焦绝对不抖”等未经验证的承诺。

若后续制作防抖对比，使用同一次真实录制的原片和稳定输出，披露倍率、裁切与参数，保持播放速度和展示尺寸一致；不要使用不同拍摄段或 AI 生成素材模拟效果。
