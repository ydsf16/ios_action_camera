# 设置与导出配色 · 0.6.1

用户反馈设置与导出界面以黑白为主，视觉单调。此次保留页面结构与操作路径，通过颜色、分组背景与主要按钮改善辨识度。

- 深蓝灰背景与稍亮的卡片区分页面和内容。
- 青绿色用于保存、导出、开关及分辨率选中状态；按钮使用深色文字。
- 稳定强度使用蓝色，裁切使用紫色，曝光使用暖黄色图标。
- 导出成功后按钮显示绿色与勾选；处理期间仍保持禁用，避免重复操作。
- 1080p / 2.8K 使用直接点选的卡片，选中状态同时显示勾选并提供 VoiceOver selected trait；较大辅助字体下改为纵向排列。
- 原片／稳定切换、录制、时间同步、算法、裁切规则与导出文件处理逻辑保留。
