# 第一步验收

## 本地检查范围

- `swift test`：时间原点、丢帧时间间隔、异常时间拒绝、运动预缓存、manifest 精度和 CSV 收尾。
- Xcode iOS Release 无签名编译、模拟器 Debug 编译。
- 模拟器启动检查权限和无相机提示；模拟器不能证明真实录制成功。

2026-09-11：Xcode 26.3 下 iOS Release、Simulator Debug 编译通过；4 项 Swift 测试及 3 项 Python 录制包审计测试通过。实际启动模拟器，检查了拍摄控件、无相机提示和素材空状态。当前可发现的 iPhone 均不可连接，尚未进行装机录制验证。

## 真机必做

1. **权限**：首次允许相机／麦克风／运动；拒绝后从系统设置恢复，应用可重新准备。
2. **画面与声音**：分别使用 0.5× 和 1× 拍摄至少 15 秒；竖屏观看文字、方向正常，拍手检查音画关系。
3. **时间与数据**：整包导出后运行 `python3 scripts/audit_recording.py <文件夹>`。核对成功帧数、单调时间、IMU 前后覆盖、K 完整率、EIS 实际值；录制 2 分钟再检查时钟映射残差。
4. **帧率**：30fps 实际帧间隔、`drops.csv` 与缺口一致。强烈运动时检查是否大量丢帧或 IMU 缺口。
5. **保存**：原片可反复播放；保存相册保留方向和声音；重启应用素材仍存在。
6. **中断**：录制后切后台、锁屏、接入会占用相机的系统功能，检查自动收尾及返回后继续拍摄。
7. **连续使用**：连续 10 段，确认无覆盖文件、无串段；较长录制检查发热、实际内存、储存增长。
8. **桌面对照**：使用原始时间映射接入 Gyroflow，再核验视觉时间同步；本次单元测试不替代此项。

异常素材也保留整包，不手改时间或覆盖原文件。
